Settings

Configure the local AI model and see how to reach this app from other devices.

AI mode

Managed Local AI is the easy path — Kayock starts and configures your local models for you (see the AI page). External / Advanced Server is for anyone who'd rather run and point at their own OpenAI-compatible server manually.

Automatically unload answering model after inactivity

Frees up RAM when you're not actively using Kayock. Only the answering model (llama-server) is unloaded — manual search stays ready. Asking a question or running OBD diagnosis resets the timer. The next Start AI (or the next question) loads it again normally.

Advanced AI Settings

Manually specify chat & embedding servers

Works with Ollama or any OpenAI-compatible server. Only used when AI mode above is set to "External / Advanced Server" — in Managed mode, Kayock overwrites these automatically whenever you Start AI.

Managed model launch options (context window, GPU flags)

Applies when Kayock starts llama-server for you. The context window defaults to {{ settings.llm_context_size }} (the value Kayock has always used) — raise it if your machine has memory to spare; lowering it below 512 is not applied. GPU handling is left to your llama-server build: CPU-only and GPU builds work with identical settings, and you can pass GPU flags (e.g. --n-gpu-layers 99) explicitly below — nothing GPU-specific is ever assumed.

Conversations & context budget

How many previous chat messages are included when you ask a follow-up in a saved chat session. Retrieval and verification always run fresh on the current question regardless of this budget — it only controls how far back the conversation's wording context reaches. Raise it for longer memory; the model's context window (above) is the real ceiling.

Interface

The toolbar button (or the t key) overrides this for the current device until you pick "Follow system" again.

Specification extraction

When several manuals contain the same specification (e.g. an owner's manual and a service manual), the filename keywords below decide which manual is preferred first — in order. Every result still shows which document and page it came from.

Online Automotive Sources

Optional lookups against official, free government/industry sources to supplement (never replace) your uploaded manuals — a VIN decode, safety recalls, and standard OBD-II code definitions. Your manuals, questions, and retrieved excerpts are never sent anywhere. Kayock works fully offline either way.

Standard OBD-II code definitions are served from a small built-in offline reference (no suitable free online source exists yet) — they work with or without internet access and aren't affected by this toggle.

System diagnostics

A read-only snapshot of the local environment — Python, data folder writability, file-picker availability, llama-server / Ollama discovery, and GPU presence (informational only: Kayock never assumes a GPU). Nothing is installed or changed by running this.

Background jobs

Indexing and reindexing run through a persistent local queue with progress, retries, and cancellation. Jobs interrupted by a crash or restart are re-run automatically — never lost.

Usage metrics

Local counters about retrieval and verification — kept in this installation's database, never sent anywhere.
